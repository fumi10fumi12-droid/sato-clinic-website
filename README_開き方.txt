佐藤医院｜静的Webサイト 修正版
===========================

【1. まず表示だけを確認する場合】
  OPEN_SatoClinic.html をダブルクリックしてください。
  6ページのHTML / CSS / 画像が1つのHTMLに入っています。
  npm・Live Serverは不要です。予約画面やスライド表示にはJavaScriptを使用します。
  上のメニューで6ページの表示を切り替えられます。

【2. VS Code / Codex で編集する場合】
  ZIPを「展開（解凍）」してからフォルダーを開きます。
  index.html    トップページ
  news.html     お知らせ
  medical.html  診療内容
  about.html    当院について
  hours.html    診療時間・所在地
  faq.html      よくある質問
  css/style.css 共通スタイル
  img/          写真・ロゴ・地図

  通常の6ページの画像は全て ./img/ 内を参照します。
  index.html等は同じ階層にcss/とimg/を残して開いてください。
  表示用OPEN_SatoClinic.htmlは単体で開きますが、画像やCSSを修正するには各ソースを編集してください。

【補足】
  PCの横幅1440px固定レイアウト。スマホ最適化は未実装です。
  フォントはShippori AntiqueをGoogle Fontsから読み込みます（オフラインでは代替フォント）。
  予約フォームは入口で診療科目を選択後、「空き日時 → 予約者情報 → 確認」の3段階で操作できます。
  空き枠の○・△・×は診療時間に合わせた固定サンプルです。実際の予約状況ではありません。
  予約データとの連携、情報の送信・保存、実際の予約登録は行いません。
  最後まで進むと「入力内容の確認が完了しました」と表示します。
  予約画面を閉じると入力した情報は消去されます。
  医院の電話番号・住所などは提供された架空のサンプルです。
  GitHub/Netlifyへの公開・pushは一切行っていません。
